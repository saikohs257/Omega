# Omega System Integration Status V1

## Purpose

This document freezes the scope of the current integration pass: assemble the complete recoverable Omega organism without silently promoting historical or experimental semantics to canonical runtime law.

## Organism

1. BentAxis — evidence, provenance, capsules, hash chains, replay-facing memory.
2. Colony — distributed exploration/work scheduling; coordination through BentAxis traces.
3. Atlas / TESSERACT — representation/topology layer; historical TESSERACT semantics remain evidence-classified until recovered and validated.
4. Hypergraph — higher-order relation representation.
5. Simplicial — compositional topology representation.
6. Sheaf — local-to-global consistency representation.
7. TIAMAT — deterministic guarded structural-dynamics runtime.
8. Court — admissibility/adjudication boundary.
9. Oracle / ERK — authority, proposals, adversarial challenge, bounded evolution.
10. E.N.D. / Darwin's Pond — bounded mutation/exploration and holdout/test firewall.

## Integration rule

Current `main` remains the implementation authority. Historical branches are source material, not canonical runtime authority. Integration should preserve existing current-main implementations and only overlay recovered modules when they are absent or explicitly required by the current experiment surface.

## Verification rule

CI must establish:

- package importability across the organism;
- deterministic replay and invariant tests;
- calibration/probability-contract tests;
- tournament AUC/Brier machinery;
- architecture/module import coverage;
- no silent authority promotion.

## Current finding

Current `main` already contains BentAxis, Colony, Oracle, Court, runtime/evidence/constitutional components, and the architecture/archaeology documentation. The current integration branch adds the recovered TIAMAT calibration/diagnostic/probability-contract stack and its experimental tests while preserving the current-main runtime surface.

## Scientific boundary

AUC/Brier outputs from synthetic tournament worlds are implementation validation, not empirical validation of real-market TIAMAT performance. Real replay/holdout evaluation remains a separate scientific gate.
