## State labels

Every deposited object must carry one of:

- `CANONICAL` — current source of authority
- `ACTIVE_RESEARCH` — executable research artifact, not yet promoted
- `SHADOW` — useful observation, no decision authority
- `ANNOTATION_ONLY` — local routing/watch-band value only
- `AUDIT_ONLY` — retained for diagnosis or negative knowledge
- `PROVISIONAL` — promising but unresolved
- `SUPERSEDED` — preserved for lineage, not live semantics
- `ARCHIVE_ONLY` — historical source retained for reconstruction
- `MISSING_SOURCE` — known to exist outside GitHub but exact source bytes are not yet deposited

## Non-negotiable deposit laws

1. Never overwrite an historical implementation to make it look current.
2. Preserve original filenames when they are provenance-bearing.
3. Put superseded versions under an explicit archive/lineage path when needed.
4. Every executable artifact gets a provenance note.
5. Every research result names its data source, target, estimator, temporal protocol, and metric polarity.
6. Negative results remain searchable.
7. A broken evaluator does not invalidate the artifact it evaluated.
8. No sidecar is promoted because of one metric.
9. Complexity must earn its keep.
10. Manual workflows are the default for archaeological / forensic experiments.
