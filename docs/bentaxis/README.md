# BentAxis / Tesseract canonical substrate

This directory records the verified BentAxis/Tesseract material deposited from the June 14, 2026 handoff set.

## Canonical relationship

- **BentAxis** — evidence substrate, compression, capsules, ledgers, courts, and stigmergic traces.
- **Tesseract / Atlas** — topology/index/routing layer over BentAxis evidence.
- **TIAMAT** — deterministic runtime/controller consuming the substrate; it is not a replacement for BentAxis.

## Provenance

The six uploaded archives were fully unpacked locally before repository modification. See `ARCHIVE_MANIFEST_20260614.md` for exact SHA-256 hashes and extraction counts.

The repository's existing canonical build order already places BentAxis first and Atlas (TESSERACT) before TIAMAT. This deposit preserves that architectural boundary rather than collapsing the substrate into the TIAMAT runtime.
