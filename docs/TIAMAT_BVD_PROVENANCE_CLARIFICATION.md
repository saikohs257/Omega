# TIAMAT B/V/D Provenance Clarification

Status: frozen reconciliation note.

`B`, `V`, and `D` are real fields in the current **canonical TIAMAT M3 identification scaffold** (`tiamat/state.py`) and may be used as a research/visual reduced-state coordinate system. Their presence in the scaffold does **not** establish that literal B/V/D columns existed in the recovered historical replay corpus.

The tested historical artifact `hf9_tiamat_v21_hidden_pattern_full_completion_20260614`, using `HIDDEN_PATTERN_AUDIT_ROW_SUBSTRATE.csv`, contained no literal canonical B/V/D fields. Historical predictive evidence instead used observed replay variables such as `LiveDeficit`, `SimpleShock`, `RecoveryWeakness_v1`, pressure proxies, run age, and transition/run fields.

Therefore:

- Canonical scaffold B/V/D: **confirmed as an implementation candidate**.
- Historical replay B/V/D columns: **not found in the tested artifact**.
- D/V/B as visual diagnostic coordinates: **permitted**.
- D/V/B as claimed historical variables: **prohibited without a source artifact defining them**.
- Any historical mechanism inference must use source-backed variables first.

This distinction is mandatory for future TIAMAT experiments so the identification scaffold is not accidentally presented as archaeological evidence.
