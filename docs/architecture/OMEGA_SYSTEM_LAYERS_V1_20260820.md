# OMEGA SYSTEM LAYERS V1

Date: 2026-08-20

## System shape

Omega is not one predictor. It is a layered governor / evidence / routing system.

```text
                       OMEGA
                          |
        +-----------------+-----------------+
        |                 |                 |
     GOVERN          EVIDENCE           SENSING
        |                 |                 |
  Oracle/TIAMAT      BentAxis          Domino/UTV
  Hazard             Proof/Capsules    Motifs/Timing
  Hinge              Provenance        PatternShift
  Seam               Replay            PatternSift
  Senate             Restore           Necronomicon
  Blackadder
        |
        +-----------------+
        |                 |
   TOPOLOGY/ROUTING   DIAGNOSTICS
        |                 |
     Tesseract         COMPASS
     Circuit            Sidecars
     Q4 Board           Calibration
     Rail/Trellis       Failure maps
```

## Authority order

1. Raw/source evidence
2. Derived state reconstruction
3. Mechanism-specific diagnostics
4. Tesseract/topology routing
5. Senate policy selection
6. Blackadder trust/friction audit
7. External diagnostics / sidecars
8. Historical interpretation

A lower layer must not silently become the authority of a higher layer.

## Core laws

- Prediction is not permission.
- Diagnostics do not auto-promote.
- Annotation is not voting authority.
- Route selection is not policy authority.
- Exact restore beats elegant compression.
- Facts precede interpretations.
- Late information cannot be used to justify an earlier decision.
- Negative evidence remains evidence.
- A failed component is not necessarily a useless component.
- Complexity must earn its keep.

## Governor stack

### Oracle / TIAMAT

Stateful burden/hazard/phase decision machinery. TIAMAT is the runtime decision engine in the current architecture.

### Hazard

Structured hazard channel. Important canonical outputs include hazard_raw, hazard_score, hazard bucket/context, entry path, episode age, duration bucket, regime, and hazard arms.

### Hinge

Fragility / prior-state lane. Current architecture treats it as local structural context, not an automatic global predictor.

### Seam

A local transition/watch-band geometry and annotation layer. Seam outputs are not a universal class predictor and do not automatically enter Senate voting semantics.

### Senate

Institutional decision layer. Seats can be promotable, diagnostic-only, shadow, or annotation-only. The Senate can choose policy without granting one component king-like control.

### Blackadder

Decision-friction / trust-calibration layer. It compares the full/ornate path with a stripped spine and measures divergence/path tax. It is a controller health instrument, not alpha.

## Evidence stack

### BentAxis

Structure-aware archival planner / byte-exact evidence compiler. AxisControl determines contest context, route candidates bid, the planner selects non-overlapping winners, and exact verification decides whether a result may be trusted.

### Provenance

All experiments and artifacts should carry source, builder/version, data target, metric contract, and commit identity.

### Replay

A run must be reconstructible from preserved evidence rather than remembered prose.

## Topology stack

### Tesseract

Multidimensional topology/router layer organizing cells, axes, legal transitions, and contextual state.

### TESSERACT_CIRCUIT

Circuit-board interpretation of Tesseract: nodes/states, legal edges, edge pull, impedance, conductance, capacitance, continuity, and release gates. Q4 board experiments are research/validation layers and must not silently become universal policy.

## Sensing / diagnostic stack

- Domino / UTV timing and spacing
- motif recurrence
- backbone / sequence clock
- clean-vs-gappy sequence quality
- PatternShift discovery
- PatternSift hostile filtering
- Necronomicon failure memory
- COMPASS advisory diagnostics
- sidecar calibration/failure surfaces

## Data-flow doctrine

```text
source
  -> snapshot
  -> derived state
  -> mechanism features
  -> topology/cell representation
  -> Senate policy
  -> Blackadder audit
  -> action
  -> aftermath
  -> replay/evidence capsule
```

The action boundary is sacred. Future outcome information belongs only after the action.
