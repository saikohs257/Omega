# OMEGA — NEGATIVE KNOWLEDGE LEDGER V1

The system must preserve what lost, why it lost, and whether the loss is about the concept or the evaluator.

## Current preserved findings

### Seam / Hinge

Status: local / annotation / routing context.

They are retained because local structural context can matter even when global prediction fails.

Do not promote them into universal predictors without isolated evidence.

### Novelty Guard

Status: provisional / reserve-bench candidate.

Interesting novelty escalation is retained as a monitored pattern, not canonical policy authority.

### Recovery obstruction

A previously examined proxy panel had the recovery-obstruction field entirely null. That is an unresolved source/build problem, not evidence that recovery obstruction is absent from the underlying system.

### Re-entry / recovery

Single repair credibility was weak. Sequential repair-failure patterns were more interesting. This motivated sequence/cascade analysis rather than treating episodes as independent.

### Activation

Activation should not be interpreted as a generic hazard-amplification signal. In the severity work, its relationship with carry was antagonistic: high carry plus low activation was the dangerous state; high activation could represent an engaged defense response.

### Carry / burden

Carry can be highly predictive for some labels and mechanical in some paths. It is not a universal substitute for response quality.

### Path specificity

Path changes the meaning of timing and feature value. A universal age gate is not justified when path-specific gates show different behavior.

### Blackadder

Full-vs-spine divergence is not evidence that the ornate controller discovered hidden alpha. It is evidence of controller strain and should be treated as a trust-calibration variable.

### AUC inversion archaeology — corrected finding

An early broad historical parser produced an apparent cluster of near-zero AUCs. Those values were later identified as non-AUC metrics parsed from generic numeric table cells.

That result is withdrawn.

The corrected explicit-AUC screen found only two sub-.50 observations:

- `entry_ret24h` = 0.4633
- `entry_live_pressure_delta_abs` = 0.4845

Neither is a strong inversion candidate.

### Genuine rank orientation anomaly

`rr_recovery_minus_burden` independently produced:

- logistic median AUC about 0.9504
- rank(+x) median AUC about 0.0496
- rank(-x) median AUC about 0.9504

This is a genuine directionality/scoring-contract discrepancy and remains an open evaluator repair item.

### Brier / log-loss orientation

No historical Brier or log-loss inversion has been established. Brier and log-loss are lower-is-better metrics; they do not use a universal `1 - metric` transformation.

### Parser lesson

A metric archaeology tool must identify the metric column/label before interpreting a number. Generic numeric table cells are not metric identities.

## Doctrine

```text
Bad result ≠ dead variable
Bad result can mean:
    weak signal
    redundancy
    regime dependence
    label mismatch
    temporal mismatch
    estimator mismatch
    polarity/scoring defect
    parser defect
    provenance defect
```

Every future failure report should explicitly classify which of those hypotheses were tested.
