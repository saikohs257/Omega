# TIAMAT A-axis Enhancement Note V1

The supplied A-axis packages should not be merged as one runtime controller. They are best treated as a layered research family.

## Preserved findings

1. ENTER and EXIT are distinct questions and should retain separate laws.
2. EXIT release latch improves the prior EXIT behavior without changing ENTER.
3. Phase/impedance and template families contain useful residual evidence but do not establish global authority.
4. Global CHUG variants demonstrate a mute/recover tradeoff: hard mute suppresses true ENTER; recover-only admits false ENTER; balanced combinations occupy a useful ridge.
5. B_age routing is a meaningful coordinate in the supplied research: young/fresh and older/stale pockets prefer different CHUG behavior.
6. Cell-fuse fallback removes the supported worse-both pockets in the supplied replay while retaining the candidate's aggregate gain.
7. Exact trace replay establishes reconstruction reproducibility, not provenance to original TIAMAT source.

## Enhancement: route-coordinate separation

Represent the A-axis research as:

```text
Pathbook legality
      +
arrival/timing coordinate (B_age and declared cells)
      +
head-local candidate
      +
fallback law
      -> candidate runtime trace
```

Do not encode B_age, basin cells, or T3 cells as universal burden scalars. They are routing coordinates whose legality and provenance must be explicit.

## Enhancement: counterfactual cell audit

For every routed row, retain the counterfactual outputs of:

- BASE_SPLIT_LAW
- HOT
- PREC
- selected route
- cell-fuse decision

This allows later courts to determine whether the router is improving because of a genuine timing interaction or merely exploiting pocket prevalence.

## Enhancement: authority firewall

The reconstructed A-axis runtime remains `SHADOW` until it has:

- native-source provenance or an explicit reconstruction designation;
- frozen temporal provenance;
- independent chronological replay;
- cell-level worse-both audit;
- comparison against null/control families;
- probability output if entering the statistical tournament;
- explicit authority-court promotion.

No numerical score alone can cross this firewall.
